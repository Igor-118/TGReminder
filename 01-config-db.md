# 1. Конфиг и подключение к БД

## Зачем

Сейчас `main.go` сам читает `BOT_TOKEN` из env, а к БД бот не подключается вообще. Все следующие подзадачи работают с БД, поэтому сначала нужны конфиг и пул подключений.

## Что сделать

### `internal/config/config.go`

- структура `Config`: токен бота и параметры БД (`POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_DB`, `POSTGRES_HOST`, `POSTGRES_PORT` из `.env.example`);
- функция `Load() (*Config, error)`: читает env, при пустом `BOT_TOKEN` возвращает понятную ошибку;
- метод, который собирает строку подключения: `postgres://user:pass@host:port/db?sslmode=disable`.

`.env` должен быть необязательным. Сейчас `godotenv.Load()` при отсутствии файла валит бота через `log.Fatal`, а в докере переменные приходят через `env_file` и файла внутри контейнера нет. Если файла нет, просто идём дальше.

### `internal/app/app.go`

Тут собирается всё приложение.

- `Run() error`:
  - загрузить конфиг;
  - создать пул [pgx/v5](https://github.com/jackc/pgx) (`pgxpool.New`) и сделать `Ping`;
  - закрыть пул при выходе (`defer pool.Close()`);
  - запустить бота (пока тот же эхо-цикл, что сейчас в `main.go`).

### `cmd/bot/main.go`

Только вызов `app.Run()` и `log.Fatal` при ошибке.

## Готово, когда

- [ ] бот стартует, в логе видно, что к БД подключился
- [ ] при неверном пароле БД бот падает с понятной ошибкой, а не паникует
- [ ] без `BOT_TOKEN` бот падает с понятной ошибкой
- [ ] бот запускается без файла `.env`, если переменные заданы в окружении
